                           LIB DIRECTORY README

The lib directory contains prototype headers for general use. IP Pascal can use
the files themselves to represent themselves. However, it is not desirable to
distribute, or use widely, the original source files.

The files in this directory are synopsys headers, taken from the original source
files. It may one day be possible to automate these files.

Each file contains all of the global declarations, as well as the procedures and
functions global to the module. It also should contain a complete list of
external libraries it uses.
